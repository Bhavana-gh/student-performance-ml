# Student Performance Prediction using Machine Learning

## Problem Statement
Predict student final scores based on study hours, attendance, and previous exam scores.

## Technologies Used
- Python
- Pandas
- NumPy
- Scikit-learn
- Matplotlib

## Steps
1. Data loading and preprocessing
2. Feature selection
3. Model training
4. Prediction and evaluation

## Result
The model predicts student performance with good accuracy using regression techniques.
